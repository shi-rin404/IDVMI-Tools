# IDVMI-Tools
Blender plugin for 3D Migoto mods and proprietary engine level mods for the certain Doll Dressing-up PvP game

# Blender Version
3.6

# Features
## Migoto
- Auto find 3D Models and ignore 2D Models
- Auto texture option
- Auto ini writer
## Proprietary Engine
- Mesh importer
- Mesh exporter (I won't tell the tea - lol. Just use migoto tactic to export :P)

# 3D Migoto Importing
Use [XXMI-Tools](https://github.com/leotorrez/XXMITools) to importing 3D Migoto frame dumps
